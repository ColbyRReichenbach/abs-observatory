## Current Scope

The retained model docs cover:

- the master rework program for all active and planned models
- run expectancy
- win expectancy support and benchmark comparisons
- overturn calibration
- decision-value audit work
- rubric calibration
- zone and controversy audits

The dated files under `audits/` and `audits/artifacts/` are historical evidence packages. They may preserve superseded labels or earlier terminology because they capture what the audit recorded at that time.

## Documentation Rule

These docs should distinguish clearly between:

- `current model behavior`
- `reconstructed history`
- `dated audit output`

Audit artifacts are evidence. Summary docs should point back to them rather than restating them at length.
