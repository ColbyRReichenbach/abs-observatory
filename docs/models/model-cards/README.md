- known limitations

Documentation rule:

- model cards describe the current intended behavior of the live stack
- dated audit files remain the evidence package
- if the two disagree, the audit artifact wins until the card is updated
- the challenge-now card currently documents an experimental live/postgame layer, not an org-grade live optimization engine
